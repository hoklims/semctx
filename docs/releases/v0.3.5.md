# v0.3.5: exact Codex tag attestation

Semctx 0.3.5 repairs the Codex side of the immutable release-delivery proof. Codex CLI 0.147.0 can
successfully install a marketplace with `--ref v<version>` while leaving a detached checkout and no
`.codex-marketplace-install.json`. That valid host shape previously ended as
`MARKETPLACE_REF_UNKNOWN`, so no installed runtime was executed and the release workflow correctly
withheld `stable` promotion.

## What changed

When Codex does not report a marketplace ref, the verifier now records a separate Git attestation
from the admitted marketplace clone. Delivery proceeds only when all of these facts agree:

- the archived Codex install attempt is the exact official command with `--ref v0.3.5` and exited 0;
- the clone `HEAD` is the released commit;
- `refs/tags/v0.3.5` resolves to an object whose Git type is `tag`;
- that exact annotated tag peels to the released commit.

The report keeps `marketplaceRef` as `null` in this host shape. Git evidence does not become a
host-reported ref. A missing tag, a different tag, a lightweight tag, a tag on another commit, an
unrelated clone `HEAD`, or an unproven install command still blocks execution.

## v0.3.4 publication state

npm `semctx@0.3.4` is public with `gitHead`
`66b659c00e1362e058b49f7cefbaecb142a593ac`. Its release delivery job failed on Codex with
`MARKETPLACE_REF_UNKNOWN`; Claude passed. The workflow did not advance `stable`, which remained on
0.3.3, and it did not create a v0.3.4 GitHub Release. Version 0.3.5 supersedes that partial
publication only after its own tag-driven npm, Codex, Claude, stable-promotion and GitHub Release
gates complete.

## Install or upgrade

After the release gates succeed:

```bash
bunx semctx@0.3.5 install
```

Open a new Codex task after plugin installation. In Claude Code, run `/reload-plugins`, or restart
Claude Code if reload fails.

## Limits and rollback

The delivery proof establishes installed package identity and fresh CLI/MCP execution. It does not
prove that an already-running session loaded 0.3.5; activation remains a separate state. Oh My Pi
delivery is still experimental and outside this Codex/Claude proof.

Adoption, retention, contribution time and human comprehension remain **NOT_MEASURED**.

Until 0.3.5 completes every public gate, the last fully delivered stable version remains 0.3.3.
Pin `semctx@0.3.3` and `v0.3.3` for rollback. Version 0.3.3 contains the unsafe setup dry-run
behavior documented in the 0.3.4 notes, so do not run `setup --dry-run` from 0.3.3 on a valuable
checkout.
