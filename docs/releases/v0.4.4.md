# v0.4.4: workspace scope, configuration freshness and quiet Windows cleanup

Semctx 0.4.4 ships the npm CLI and both host plugins together. Bun >=1.4.0,
Codex 0.147.0 and Claude Code 2.1.229 remain the declared host baseline.

## What changes

- Workspace discovery honors configured exclusions. Excluded manifest copies cannot contest an
  in-scope identity. V2 exact-file globs and recursive subtree globs retain their file-selection
  semantics; duplicate identities inside the selected scope remain ambiguous.
- A declared `workspace:` dependency can resolve an uninstalled member's shared TypeScript
  configuration. Installed packages keep precedence; unrelated registry dependencies, ambiguous
  members and paths outside the repository do not gain a synthetic link. Configuration links
  and inherited paths refuse symlink escapes; spaced semver comparators retain their meaning.
- Ordinary v2 TypeScript and JavaScript freshness bind the manifests, workspace declaration and inherited
  configuration actually consumed by those links, including failed attempts. LF/CRLF differences
  remain equivalent. Legacy analysis and retained qualified snapshots keep their existing
  identity and resolution contracts.
- Verification accepts an unchanged CRLF Git blob in an autocrlf checkout while still rejecting
  hidden content changes and mid-capture drift.
- Recursive exclusions cover workspace links and nested unreadable directories. Discovery
  tolerates an unreadable directory only when its complete subtree is excluded. Other
  unreadable directories retain an explicit failure.
- Deferred Codex cleanup hides its child console windows on Windows.
- A pure, opt-in library policy rejects expired or already-consumed authorization capsules
  against an explicit clock and caller-owned consumption state. Age bounds retain fractional
  timestamp precision. Storage, atomic state/effect coordination and rollback remain the
  caller's responsibility; existing CLI/MCP replay does not activate this policy.
- Capsule production, schema validation and independent replay share exact timestamp ordering
  for the observation and expiry bounds of assertions and evidence providers. Their authorization
  decision rules remain separate.
- Shared validation rejects invalid timezone offsets and executable Array subclasses while
  preserving ordinary JSON replay.

The opt-in JavaScript qualification and negative-completeness boundaries are unchanged. Static
analysis does not establish runtime or business correctness.

## Install or upgrade

After publication:

```bash
bunx semctx@0.4.4 install
```

Open a new Codex task, or run `/reload-plugins` in Claude Code (restart if reload fails).
Consumer rollback uses the previously published 0.4.3 through the native host mechanism, then
reopens or reloads the host. It does not replace an immutable npm version or move `stable` manually.

## Evidence and limits

Source checks, CI, npm publication, two-host delivery and active-session loading remain separate.
The annotated tag must pass the canonical gate; npm must identify that exact commit; immutable
Codex and Claude payloads must pass delivery before the stable channel advances.

fixture. After publication it must be rerun from the exact downloaded 0.4.4 artifact before
release-phase Pages evidence is published. Candidate bytes and older observations retain their
original identities and cannot establish released-artifact evidence.
