Source commit `1fd566c87718f576e35816a4361eebb8bb28eb58` corrects four
differences found during the independent review:

- Ordinary JavaScript subject and batch outcomes use the ordinary configuration
  reasons, while retained input keeps its stricter configuration profile.
- Triple-slash references use exact retained-input Map membership, including
  on a case-insensitive compiler filesystem.
- Safe Promise await recognition requires the direct SDK property-access
  callee. Const callee aliases and computed access retain their refusal;
  direct calls, async calls and awaited Promise-value aliases keep their
  existing handling.
- Working-tree verification observes the Git diff, untracked and tracked input
  inventory, configuration metadata and HEAD again before its final helper and
  captured-file byte checks. This is a final freshness check, without an atomic
  Git/filesystem transaction guarantee.

callee-alias and same-tree HEAD defects. The initial computed-callee witness

5.9.3, established both `SOURCE_AWAIT_UNSUPPORTED` and
`SOURCE_UNRESOLVED_CALLEE_UNSUPPORTED`. The checker supplies no symbol at
the computed callee, despite a successful SDK property lookup. Both diagnostics
are therefore retained in the corrected DEV assertions. Original expectation
files and failed attempts remain historical; the two incomplete-set failures
are not canonical V2 negative evidence.
